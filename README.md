# Wil Sanchez — Consultor en Ventas

Landing page V1 para Wil Sanchez / Growth System.

## Publicación gratuita con GitHub Pages

1. Crea una cuenta en GitHub si no tienes una.
2. Crea un repositorio nuevo, por ejemplo: `wil-sanchez-web`.
3. Sube `index.html`, `styles.css` y `script.js`.
4. En GitHub entra a Settings → Pages.
5. En "Build and deployment", selecciona "Deploy from a branch".
6. Selecciona la rama `main` y carpeta `/root`.
7. Guarda. GitHub te dará una dirección pública para la web.

## Antes de publicar

- Reemplazar los bloques "FOTO DE WIL" por tu fotografía.
- Revisar textos y CTA.
- Revisar que el número de WhatsApp sea correcto.
- Más adelante conectar un dominio propio.
